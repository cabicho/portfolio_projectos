# 🚢 Otimização de Frota de Navios - Accenture

## 📋 Sobre o Projeto
Projeto completo de **Pesquisa Operacional e Otimização Matemática** para gestão de frota de navios, desenvolvido como estudo de caso para vaga na Accenture.

**Tecnologias:** Python, PuLP, Pandas, Docker, Jupyter
**Metodologia:** Pesquisa Operacional, Otimização Matemática, Análise de Dados

## 🎯 Objetivos
- Desenvolver modelo de otimização para seleção ideal de navios
- Maximizar lucro total da frota considerando restrições operacionais
- Gerar insights estratégicos através de análise exploratória
